# 🍽️ SmartMess - মেস মিল ও বিল ব্যবস্থাপনা সিস্টেম

একটি আধুনিক, দৃষ্টিনন্দন এবং ফুল-রেসপন্সিভ মেস মিল ও ইউটিলিটি বিল ক্যালকুলেটর ড্যাশবোর্ড।

---

## 🌟 নতুন ফিচার ও ডিজাইন হাইলাইটস:
- 🎨 **Glassmorphism & Gradient Design**: আধুনিক ফ্রস্টেড গ্লাস ইফেক্ট এবং প্রিমিয়াম লুক।
- 🌙 **Dark / Light Mode**: চোখের আরামের জন্য তাৎক্ষণিক ডার্ক ও লাইট থিম সুইচ করার সুবিধা।
- 📊 **KPI Dashboard Cards**: মোট মেম্বার, মোট মিল, বর্তমান মিল রেট (গ্লোয়িং ব্যাজ), মাথাপিছু ইউটিলিটি ও মেস খরচ।
- 📱 **স্লিপ ভিউ (WhatsApp/Messenger Ready)**: প্রতিটি মেম্বারের জন্য আলাদা হিসাব স্লিপ, যা ১ ক্লিকে কপি করে হোয়াটসঅ্যাপ বা মেসেঞ্জারে পাঠিয়ে দেওয়া যায়।
- ✏️ **মেম্বার তথ্য এডিট ও ডিলিট**: ভুল হলে সম্পূর্ণ মেম্বার মোছার প্রয়োজন নেই, সরাসরি এডিট করা যায়।
- 🔍 **সার্চ ফিল্টার**: যেকোনো মেম্বারের নাম দিয়ে সহজে ফিল্টার করা যায়।
- 💾 **LocalStorage Auto-Save**: ব্রাউজার রিলোড বা বন্ধ হলেও কোনো ডাটা হারিয়ে যাবে না।
- 🖨️ **Print & PDF Export**: এক ক্লিকে পুরো মেস ব্যালেন্স শিট প্রিন্ট বা PDF হিসেবে সেভ করার সুবিধা।
- ✨ **১-ক্লিকে ডেমো ডাটা লোড**: সহজে সিস্টেমটি টেস্ট করার ব্যবস্থা।

## 🚀 কীভাবে চালাবেন?

### অপশন ১ (সবচেয়ে সহজ):
- ফোল্ডারে থাকা `start-project.bat` ফাইলটিতে ডাবল ক্লিক করুন। স্বয়ংক্রিয়ভাবে সার্ভার রান হয়ে ব্রাউজারে ওপেন হয়ে যাবে।

### অপশন ২ (টার্মিনাল থেকে):
```bash
cd frontend
npm run dev
```
তারপর ব্রাউজারে `http://localhost:5173` ওপেন করুন।
